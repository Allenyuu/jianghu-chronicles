# 設計筆記：如何做一款原創武俠 TRPG

## 目標

《江湖錄：風雨十三州》要同時做到四件事：

1. 沒玩過 TRPG 的繁體中文玩家能在三分鐘內開始。
2. 門派不只是能力包，而是會把角色拉進劇情的社會身份。
3. 武功需要有派系差異與招式風味，但不以大量查表拖慢交鋒。
4. 瀏覽器版本本身能單人玩，也能在實體桌上作為角色與主持工具。

## 公開資料研究

研究只使用發行商或創作者公開的產品介紹、免費宣傳資料與官方資源，沒有抄錄付費規則內容。

### Righteous Blood, Ruthless Blades

[Osprey Games 官方介紹](https://www.ospreypublishing.com/us/righteous-blood-ruthless-blades-9781472839367/)強調鮮明而有能力的俠客、江湖疑案、社會資源，以及快速且有後果的戰鬥。這證明武俠 TRPG 不必沿用地城探索節奏；「解謎、報仇、行俠與門派關係」本身就能成為主循環。

本作採納的產品方向：從一開始便讓角色是能人，並讓每次衝突改變人物關係。

本作刻意不同之處：採用完全原創的陰陽 2D6 規則、五項屬性、非致死優先的傷痕機制，以及較明亮的俠義與選擇調性。

### Wandering Heroes of Ogre Gate

[Studio 2 Publishing 官方介紹](https://studio2publishing.com/products/wandering-heroes-of-ogre-gate)展示了大量門派、武學技巧與自創武功指引對武俠世界的價值。它提醒設計者：招式不是單純傷害數字，而是世界觀、師承與戰鬥畫面的交會點。

本作採納的產品方向：讓門派、技法與江湖勢力形成可遊玩的完整生態。

本作刻意不同之處：將內容壓縮為八門 × 四式，再以七種跨門派派系創造組合；所有門派名稱、歷史、招式與勢力關係均為原創。

### Feng Shui 2

[Atlas Games 官方資料](https://www.atlas-games.com/product_tables/AG4020)強調快速選擇原型、自由描述動作與電影感交鋒。這種「先讓玩家想像畫面，再以規則收束」的順序非常適合武俠。

本作採納的產品方向：起步快、招式描述優先、敵人不需要重複擲骰。

本作刻意不同之處：沒有時空穿越、現代槍戰或既有原型；戰鬥以玩家單次陰陽判定同時結算攻防。

## 原創核心：陰陽雙骰

一般 2D6 系統只讀總和，本作把兩顆骰賦予不同身份：

- 總和回答「做成了嗎？」
- 陰陽高低回答「氣往哪裡走？」
- 同點回答「是否出現和合轉機？」

因此每次擲骰至少產生兩個可用資訊。玩家即使得手，也可能因陰高選擇收斂；即使兩難，也可能因陽高獲得下一步反攻資源。

門檻設為 12+、9–11、6–8、5-。屬性多為 1–3，無修正的平均總和約 8–10，讓「兩難／得手」成為最常見結果；傳奇與失手都保持稀有但可見。

## 門派與派系分離

許多職業制遊戲把社會身份與戰鬥風格綁在一起。本作拆成兩層：

- **門派**回答「誰教你、誰認得你、你欠誰？」
- **武功派系**回答「你如何動手、如何解題？」

這使同門角色仍能有完全不同的打法，也讓跨越刻板印象的組合自然產生人物故事。

## 傷痕而非隨機死亡

武俠重傷往往不是故事終點，而是退隱、復仇、改練左手劍或重新理解師門的起點。因此體力歸零先留下永久傷痕，第三道傷痕才要求角色選擇退場方式。

這保留戰鬥後果，同時把角色結局的主導權留給玩家。

## Web 版的設計選擇

- 純靜態 HTML、CSS、JavaScript，不依賴後端或外部套件。
- `localStorage` 僅保存本機進度，不上傳個人資料。
- JSON 匯入／匯出讓人物卷可跨裝置或交給同桌伙伴。
- 所有核心資料集中於 `data.js`，方便社群新增門派、招式與場景。
- 主線場景以三種屬性手法呈現，讓新手直接看懂「同一問題可有不同解法」。

## 不採用的做法

- 不使用真實歷史門派作為奇觀拼貼，避免把活的文化傳統簡化成技能標籤。
- 不以成百上千招換取內容量；42 式足以形成差異，也能讓玩家記住招名與畫面。
- 不把「失手」寫成沒有進展；每個失手都揭露線索或推進威脅。
- 不讓系統替玩家決定死亡；傷痕與最後一戰保留選擇。
